# Enhanced Automatic Phase Selector with Remote Monitoring

## 1. Project Overview

The Enhanced Automatic Phase Selector is an electrical power management system designed to automatically select the most suitable power phase from available supply phases based on voltage conditions.

The system integrates a voltage sensing unit, microcontroller-based control, automatic phase selection, and remote monitoring capabilities. Its primary objective is to improve power supply reliability, reduce manual intervention, and provide users with information about the operating condition of the electrical supply.

## 2. Project Objectives

- Develop an automatic system for selecting between available power phases.
- Monitor the voltage levels of the incoming phases.
- Use a microcontroller to process voltage measurements and control phase selection.
- Incorporate remote monitoring for improved accessibility and system supervision.
- Improve power supply continuity and reduce the need for manual phase switching.

## 3. Key Features

- **Automatic Phase Selection:** Selects a suitable phase based on predefined voltage conditions.
- **Voltage Monitoring:** Continuously monitors the voltage levels of the available phases.
- **Microcontroller-Based Control:** Processes sensor readings and manages the switching operation.
- **Remote Monitoring:** Provides access to relevant system information remotely.
- **Power Supply Management:** Helps maintain a more reliable electrical supply.

## 5. Working Principle

The system monitors the voltage levels of the available power phases through its voltage sensing unit. The measured values are sent to the microcontroller for processing.

The microcontroller evaluates the voltage conditions against predefined operating limits and determines the most suitable phase for selection. It then controls the switching mechanism to connect the load to the selected phase.

The remote monitoring feature allows users to observe relevant system information, such as voltage readings and the selected phase, through a communication interface.

## 6. System Design

The project is organized into four major functional sections:

1. **Voltage Sensing Unit:** Detects and measures the voltage levels of the available phases.
2. **Control Unit:** Processes voltage readings and makes phase selection decisions.
3. **Switching Unit:** Executes the phase selection command using an appropriate switching device.
4. **Remote Monitoring Unit:** Communicates system information to a remote monitoring interface.
